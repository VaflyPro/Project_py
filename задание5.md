# Краткое пояснение
- В этом задании нужно создать данные, а именно придумать три вопроса по материалу первого и второго дня
- Оформляем их в файл my_questions.csv в том же формате, что и bank.csv
- Проверяем, что вопросы соответствуют требованиям оформлению
- Проверяем файл через check_bank.py

## «Типы вопросов»
В задании упоминаются три типа:
«Один» — вопрос с одним правильным вариантом ответа (как тест с одним выбором)
«Несколько» — вопрос, где правильных вариантов несколько (как тест с множественным выбором)
«Короткий» — вопрос, где ответ — это короткая строка (одно слово, число или несколько форм одного слова)

### «Пустая клетка»
В bank.csv есть вопросы по разным темам и уровням. Например:
- Тема «строки», уровень 1 — есть вопросы
- Тема «строки», уровень 2 — есть вопросы
- Тема «строки», уровень 3 — пусто 
«Пустая клетка» — это сочетание темы и уровня, которого нет в bank.csv. Нужно создать хотя бы один вопрос, который попадет в такую пустую клетку
Список пустых клеток — в materials/bank_format_rus.md

## Более подробный алгоритм
1) Изучаем bank_format_rus.md
- Там должно быть написано какой разделитель используется (;, ,)
- Какие столбцы есть в файле
- Какие типы вопросов бывают
- Какие темы и уровни уже заняты, а какие пустые

2) Придумываем три вопроса.
3) Выбираем уровни
Все три вопроса должны быть разных уровней
4) Выбираем номера.
Номера — от 101. Например, 101, 102, 103
5) Убедитесь, что хотя бы один вопрос — в пустой клетке
6) Оформляем файл my_questions.csv
7) Проверяем файл через запуск и через main.py
- python3 src/partner/check_bank.py datasets/my_questions.csv
- python3 src/main.py datasets/my_questions.csv
Должно вывести Вопросов: 3.
- python3 src/main.py datasets/my_questions.csv --show 101
Должен показать вопрос
