# Краткое пояснение
Нужно написать две функции:
find_question — ищет вопрос по его ID в списке всех вопросов.
question_lines — форматирует найденный вопрос для вывода на экран: берет текст вопроса и добавляет к нему пронумерованные варианты ответов (если они есть).

Эти функции будут вызываться из main.py, который уже написан. По логике main.py получает флаг --show ID, вызывает find_question, получает вопрос, передает его в question_lines, получает список строк и потом их печатает.

## Более подробный алгоритм
### Для функции find_question:
1) Принять список всех вопросов (questions) и искомый номер (q_id)
2) Нужно пройтись циклом по всем вопросам в списке
3) Для каждого вопроса проверяем, совпадает ли его id с q_id
4) Если совпадает — возвращаем этот вопрос (словарь)
5) Если цикл закончился, а вопрос не найден — вернуть None

### Для функции question_lines:
1) Принять один вопрос (словарь)
2) Создаём пустой список строк lines
3) Добавляем в в lines текст вопроса (question['text'])
4) Проверяем, есть ли у вопроса поле с вариантами ответов (например, 'options') и не пустое ли оно
5) Если варианты есть — идём по ним циклом с нумерацией (начиная с 1) и добавить каждую строку в формате "1) вариант"
6) Возвращаем список lines

### Важно: я не знаю точный формат хранения вариантов ответов, всё зависит от содрежания bank_format_rus.md Если варианты хранятся в одном поле через разделитель,сначала придётся разбить это поле на список

'''python
# Функция поиска вопроса по ID
def find_question(questions, q_id):  # questions - список всех вопросов, q_id - искомый номер
    for q in questions:  # перебираем все вопросы в списке
        if q['id'] == q_id:  # сравниваем id текущего вопроса с искомым
            return q  # если нашли - возвращаем словарь с вопросом
    return None  # если цикл закончился, а вопрос не найден - возвращаем None

# Функция форматирования вопроса для вывода
def question_lines(question):  # question - один словарь с вопросом
    lines = []  # создаём пустой список строк для вывода
    lines.append(question['text'])  # добавляем текст вопроса (первая строка вывода)
    # Проверяем, есть ли у вопроса варианты ответов
    if 'options' in question and question['options']:  # если поле 'options' существует и не пустое
        for i, option in enumerate(question['options'], 1):  # перебираем варианты с нумерацией от 1
            lines.append(f"{i}) {option}")  # добавляем строку вида "1) print"
    return lines  # возвращаем список строк, который main.py напечатает 
    '''
