# Краткое пояснение
В Задании 1 мы создали функцию load_bank, но в файле bank_dirty.csv могут быть испорченные строки — например, где не хватает полей или где id/level не числа (я не знаю точные критерии)

Нужно доработать load_bank так, чтобы:
1) Испорченные строки не попадали в список вопросов
2) Функция считала, сколько таких строк было
3) Программа возвращала число пропущенных строк, вместе со списком вопросов
4) main.py уже написан, поэтому при skipped > 0, он печатает вторую строку Пропущено строк: N. Если skipped == 0, вторая строка не печатается

## Испорченные строки
Точное определение испорченных строк должно быть в materials/bank_format_rus.md. У меня будет 5 проверок, но нужно сделать проверки именно на то, что будет указано

Для примера в моем случае строка считается испорченной, если:
- В ней меньше 5 полей (не хватает данных)
- Поле id не является целым числом
- Поле level не является целым числом от 1 до 5
- Поле topic пустое
 -Поле question пустое
- Поле answer пустое

## Более подробный алгоритм
### Для функции load_bank:
1) Принимаем путь к файлу (file_path)
2) Создаём список questions и счетчик skipped = 0
3) Открываем файл
4) Пропускаем заголовок
5) Проходимся циклом по всем строкам:
- Проверка 1: Если в строке меньше 5 полей — увеличиваем skipped и переходим к следующей строке
- Проверка 2: Пробуем преобразовать row[0] в число (int). Если не получается — увеличиваем skipped
- Проверка 3: Пробуем преобразовать row[2] в число (int). Если не получается — увеличиваем skipped
- Проверка 4: Если topic, question или answer пустые — увеличиваем skipped
6) Если все проверки пройдены — создаём словарь question и добавляем его в questions
7) Возвращаем значения questions и skipped.
Все проверки делаем до создания словаря!

```python
import csv  #модуль для разбивания строк
def load_bank(file_path): #создаём нашу функцию, file_path - здесь должен быть путь к файлу (например datasets/bank.csv)
    questions = []  #пустой список
    skipped = 0  #кол-во пропущенный строк
    with open(file_path, 'r', encoding='utf-8') as f:  #открываем файл, возможно он должен открываться по другому, смотрим по заданию
        reader = csv.reader(f, delimiter=';')  #создаём объект для чтения нашего файла, разделитель настраиваем в зависимости от содержимого файла
        header = next(reader, None)  #пропускаем заголовок
        for row in reader:  #перебираем все строки через цикл
        #Важный момент: посмотреть можно ли использовать конструкцию try/except, как аналоги можно использовать регулярки или проверку через .isdigit()
            if len(row) < 5:  #Проверка 1: достаточно ли полей в строке
                skipped += 1
                continue
            try:
                id_val = int(row[0]) #Проверка 2: id — целое число?
            except ValueError:
                skipped += 1
                continue
            try:
                level_val = int(row[2])  #Проверка 3: level — целое число?
            except ValueError:
                skipped += 1
                continue
            if level_val < 1 or level_val > 5:  #Проверка 4: level в диапазоне 1-5?
                skipped += 1
                continue
            if not row[1] or not row[3] or not row[4]: #Проверка 5: обязательные поля не пустые?
                skipped += 1
                continue
            question = {  #самый важный момент, здесь преобразуется строка в словарь, чтобы мы могли удобно обращаться к каждому элементу через имена (ключи), а не только через индексы
                'id': int(row[0]),
                'topic': row[1],
                'level': int(row[2]),
                'text': row[3],
                'answer': row[4]
            }  #если в итоге по заданию словарь окажется не нужен просто используем конструкцию question = [int(row[0]), row[1], int(row[2]), row[3], row[4]]
            questions.append(question)  #добавляем словарь в список 
    return questions, skipped  #возвращаем число полученных вопросов и кол-во пропущенных строк (по заданию 0)
```
