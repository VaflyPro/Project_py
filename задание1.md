
# Задание 1. Сколько вопросов

## Формулировка
> Напиши тело функции «load_bank» в «src/bank.py»: она читает файл банка и возвращает два значения: список всех вопросов и число пропущенных строк — пока это «0».

## Краткое пояснение
Нужно прочитать CSV-файл «bank.csv», пропустить заголовок, каждую строку превратить в словарь (описание вопроса) и собрать все словари в список. Вернуть список и число пропущенных строк (0).

### Примерный код
```python
import csv

def load_bank(file_path):
    questions = []
    skipped = 0
    
    with open(file_path, 'r', encoding='utf-8') as f:
        reader = csv.reader(f, delimiter=';')
        header = next(reader, None)
        
        for row in reader:
            question = {
                'id': int(row[0]),
                'topic': row[1],
                'level': int(row[2]),
                'text': row[3],
                'answer': row[4]
            }
            questions.append(question)
    
    return questions, skipped
```
